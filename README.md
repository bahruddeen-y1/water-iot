# โปรเจ็กต์ IoT ตรวจสอบคุณภาพน้ำ

โปรเจ็กต์ IoT สำหรับตรวจสอบคุณภาพน้ำด้วย ESP32 และแสดงผลผ่านหน้า Dashboard โดยใช้ Firebase Realtime Database เป็นตัวกลางระหว่างอุปกรณ์กับหน้าเว็บ นอกจากนี้ หน้า Dashboard ยังสามารถใช้เป็นเป้าหมายสำหรับทดสอบการทำงานของ UI ด้วย Playwright ได้

## โครงสร้างโปรเจ็กต์

- `main/main.ino` — โปรแกรมสำหรับ ESP32 อ่านค่าเซนเซอร์ ควบคุมปั๊ม และสื่อสารกับ Firebase
- `main/config.h` — ตั้งค่า Wi-Fi, Firebase, Discord Webhook และค่าปรับเทียบเซนเซอร์
- `dashboard/index.html` — หน้า Dashboard สำหรับดูข้อมูลและควบคุมระบบ

## ความสามารถ

- อ่านค่า EC และอุณหภูมิจากเซนเซอร์
- แสดงสถานะอุปกรณ์และข้อมูลบน Dashboard แบบเรียลไทม์
- ควบคุมปั๊มน้ำในโหมดอัตโนมัติหรือโหมดแมนนวล
- ตั้งค่าเกณฑ์ EC และอุณหภูมิผ่าน Dashboard
- แสดงกราฟข้อมูลย้อนหลังและข้อมูลพยากรณ์
- ส่งการแจ้งเตือนผ่าน Discord

## อุปกรณ์และไลบรารี

- บอร์ด ESP32
- เซนเซอร์อุณหภูมิ DS18B20
- เซนเซอร์ EC
- Relay และปั๊มน้ำตามการติดตั้ง
- ไลบรารี Arduino: `FirebaseESP32`, `OneWire` และ `DallasTemperature`

## เริ่มต้นใช้งาน

1. ติดตั้ง Arduino IDE หรือ PlatformIO พร้อม ESP32 board support และไลบรารีที่ระบุข้างต้น
2. กำหนดข้อมูล Wi-Fi, Firebase และ Discord ใน `main/config.h` ให้ตรงกับสภาพแวดล้อมของคุณ
3. ตรวจสอบการต่อวงจรและค่า GPIO ใน `main/main.ino` ให้ตรงกับอุปกรณ์จริง
4. เปิด `main/main.ino` แล้วอัปโหลดไปยังบอร์ด ESP32
5. เปิดหน้า Dashboard ผ่านเว็บเซิร์ฟเวอร์ โดยรันคำสั่งจากโฟลเดอร์โปรเจ็กต์:

   ```bash
   python3 -m http.server 8000 --directory dashboard
   ```

6. เปิด [http://localhost:8000](http://localhost:8000) ในเบราว์เซอร์ และตรวจสอบการเชื่อมต่อ Firebase

> อย่าเผยแพร่ `main/config.h` ที่มีข้อมูลรับรองหรือ Webhook ลงใน repository สาธารณะ

## ทดสอบหน้าเว็บด้วย Playwright

หน้า `dashboard/index.html` สามารถใช้เป็นหน้าเป้าหมายสำหรับเขียนและรันทดสอบ UI ด้วย Playwright ได้ โดยให้เปิดหน้าเว็บผ่านเซิร์ฟเวอร์ในขั้นตอนข้างต้น แล้วกำหนด URL ของหน้าเว็บเป็น `http://localhost:8000`

ขณะนี้ในโปรเจ็กต์ยังไม่มี Playwright dependency, config หรือ test script การเพิ่มและตั้งค่าชุดทดสอบจึงเป็นขั้นตอนที่ต้องทำแยกต่างหาก
